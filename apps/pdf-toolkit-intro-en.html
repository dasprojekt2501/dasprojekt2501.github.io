PDF Toolkit

Split, merge, extract, rotate, reorder, crop, and compress PDFs entirely in your browser.
No installation, no uploads, and completely free.

Web Browser

Features
✂️
Split
Divide a PDF into multiple files at any page
📎
Merge
Combine multiple PDFs into one in any order
📋
Extract
Pick specific pages and save them as a new PDF
🔄
Rotate
Rotate any page in 90° increments
↕️
Reorder
Drag and drop to rearrange pages
📐
Crop
Trim page margins or unwanted areas by adjusting the visible region
🗜️
Compress
Set a target file size and let auto-calibration do the rest
🔒 All processing happens locally in your browser. Your PDF files are never sent to any server.
📥 Download the HTML file to use the toolkit offline, anytime.
⚠️ Compression re-renders each page as an image, so text search and copy will be disabled in the compressed PDF.
