# 新聞記者シューティング ── ストーリー設計

## 背骨：残るものの物語

『平家物語』は、滅んだ家の記録である。平家は残らなかった。
残ったのは、それを語り継いだ琵琶法師のほうだった。

| 平家物語 | このゲーム |
|---|---|
| 平家一門 | 新聞社 |
| 栄華 → 滅亡 | 発行部数 10,000,000 → 0 |
| 奢れる人 | 奢れる上司（上層部） |
| **琵琶法師** | **主人公（記者）** |

主人公は平家ではない。**平家を語る側**である。
だから会社が滅んでも主人公は残る。最後に立っているのは業界の残骸の上。

死ぬのは新聞社という**容れ物**であって、取材して書くという行為ではない。

## トーン

強烈な風刺コメディ。最後まで笑いは引っ込めない。
ハラスメントの文言はそのまま据え置く。変えるのは**ダメージ値だけ**。

---

## 序（初回のみ・5秒・スキップ可）

MISSION START の直後に一枚だけ挟む。
部数が減り続ける画面を「失敗」ではなく「物語」として読ませるための前置き。

```
祇園精舎の鐘の声、諸行無常の響きあり。
奢れる上司も久しからず、
唯春の夜の夢のごとし。

──新聞社もまた、ひとつの家である。

その家が滅ぶまでを、あなたは書きつづける。
```

最初の二行で笑わせ、三行目で真顔に戻る。この落差がトーンの宣言になる。
第三幕の仕掛け（撃っても効かなくなること）には触れない。
「家が滅ぶ」のは前提であって、種明かしではない。

## 三幕構成

| | 第一幕 | 第二幕 | 第三幕 |
|---|---|---|---|
| **年** | 2001 | 2026 | 2030 |
| **開始部数** | 10,000,000 | 5,000,000 | 1,000,000 |
| **減少** | 200,000/秒（2%） | 150,000/秒（3%） | 50,000/秒（5%） |
| **素の持ち時間** | 50秒 | 33秒 | 20秒 |
| **敵** | ガラケー・PC（まばら） | 📱 炎上（撃つと増える） | AI・無関心 |
| **ボス** | デスク（社会部部長） | 編集局長（出世したデスク） | 会長（老いて朽ちる） |
| **暴言のダメージ** | 15 | 8 / 5 | **0** |
| **プレイヤーの動詞** | 撃つ | 撃つほど不利 | **拾う** |
| **📰 の効果** | 部数回復 | 部数回復 | **読者に加算** |
| **平家** | 奢れる上司も久しからず | 猛き上司も遂にはほろびぬ | 偏に風の前の塵に同じ |

幕が進むほど**短くなる**。滅びが加速し、テンポも上がる。

### 第一幕｜2001年 ──「奢れる上司も久しからず」

まだ羽振りがいい。社旗がでかい。経費で飲む。
デジタルは「あんなもの流行らない」と言われている。

ボスは**デスク（社会部部長）**。ハラスメント全開。奢れる上司そのもの。
笑いは全開。ここが風刺の本場。

### 第二幕｜2026年 ──「猛き上司も遂にはほろびぬ」

SNS。炎上。「ネットの声」。
社内に DX 推進室ができるが、やっていることは紙面の PDF 化。

ボスは**編集局長になったデスク**。出世している。
最大の風刺は「**無能なほど上に行く**」こと。
第一幕で殴った男が、今度は上から降ってくる。

炎上は**撃つと分裂して増える**。反論するほど不利になる。

### 第三幕｜2030年 ──「偏に風の前の塵に同じ」

ボスは**役員室で老いた会長**。第一幕・第二幕と同じ男。

最終ボスは、プレイヤーが倒すのではなく**勝手に朽ちる**。
撃っても倒れない。というか、もう倒れている。
第一幕とまったく同じ暴言を吐き続けているが、誰も聞いていない。

## 中心となる仕掛け

### 1. 暴言のダメージが、時代とともに減衰する

文言は据え置き。同じ言葉が、同じ顔から、同じ勢いで飛んでくる。
**でも、もう何も削れない。**

| | 2001 | 2026 | 2030 |
|---|---|---|---|
| 「使えねえな」 | 15 | 8 | **0** |
| 「彼氏いるの？」 | 15 | 5 | **0** |

第三幕でダメージ0の暴言が当たったとき：

```
かすり傷ひとつつかない
```

言葉が止むのではなく、**効かなくなる**。
盛者必衰を、数値で殴らずに数値で語る。

### 2. ボスは三幕を通じて同じ一人の男

デスク → 編集局長 → 会長。
出世し、肥り、老い、朽ちる。描画は同じ関数を年齢パラメータで変える。

盛者必衰を、一人の人物の連続的な変化として見せる。

### 3. 第三幕では、部数ゼロが敗北ではなくエンディング

```
第一幕・第二幕：  📰 を拾う → 部数が回復する（新聞社を延命させている）
第三幕：          📰 を拾う → 読者が増える（部数は止められない）
```

拾っても拾っても部数のバーは下がり続ける。でも別のカウンタが増えていく。
プレイヤーは**新聞社を救えないことを、手で理解する**。

会長は勝手に朽ちる。部数は勝手にゼロになる。
プレイヤーにできるのは、瓦礫から新聞を拾って、誰かに渡すことだけ。

盛者必衰はプレイヤーが起こすことではない。**放っておいても起こる。**

第三幕に部数による敗北はない。やる気（HP）ゼロで倒れる敗北のみ残す。

## 三人の記者 ＝ 容れ物との三つの関係

| | 立場 | 容れ物との関係 | 結末 |
|---|---|---|---|
| 🕵️‍♂️ ハードボイルド | ベテラン。紙の人間 | **会社を信じていた** | 一緒に沈む。だが最後に一冊書く |
| 👩‍💼 ビジネスウーマン | 中堅。ハラスメントの矢面 | **出ていく** | 告発して、外で書き始める |
| 👽 ホログラム | 最も若い。契約記者 | **最初から中にいない** | 会社が滅んだことにすら気づかない |

沈む／出る／最初からいない。
**三人とも書き続ける**、というのが背骨の帰結。

## エンディング

第三幕をクリアすると、UI のカウンタの**単位が入れ替わる**。

```
発行部数     0
読者         1
```

ゲーム全体が「大きな数字が減っていく話」だった。
その数字が0になった瞬間に、別の数字が1になる。

> **奢れる上司も久しからず。**
> **書いた者だけが残った。**
